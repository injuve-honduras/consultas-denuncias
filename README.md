# Consulta de denuncias INJUVE

Interfaz inicial independiente para GitHub Pages.

- `index.html`: formulario de consulta.
- `assets/css/styles.css`: estilos institucionales.
- `assets/js/app.js`: validación visual inicial.
- `assets/img/logo-injuve.png`: coloca aquí el logotipo oficial.

**Estado:** esta versión es solo la interfaz; todavía no consulta registros reales. Antes de publicarla para uso real, debemos implementar y probar un mecanismo seguro de acceso al backend, controles contra intentos automatizados y las medidas institucionales de privacidad.
